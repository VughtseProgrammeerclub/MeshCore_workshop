# MeshCore workshop
Basiscursus MeshCore

Nodig voor de workshops
Naast een laptop met Chrome of Edge en optioneel een IOS of Android smartphone heb je nog wat aanvullende hardware nodig.

Minimaal
1x USB-C datakabel (zorg dat het echt een goede datakabel is)
1x Heltec Wi-Fi LoRa 32 V3 - ESP32-S3 - SX1262 868MHz  € 21,00 

Advies
Bestel een extra Heltec board als je naast de workshops ook thuis gaat experimenteren.  Daarvoor heb je minimaal 2 boards nodig.

V4 board?
Er is sindskort een Heltec V4 board. Koop je dat voor deze workshop dan kan het zijn dat sommige dingen niet helemaal werken zoals in de workshops gedemonstreerd wordt.
Alle documentatie en downloads voor de workshops zijn voor V3. 
We hebben wel getest met v4 en deze kan wel gebruikt worden voor de workshop/
